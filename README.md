# 咔嚓卡片 · 微信小程序（测试号 / 无后端）

把「相册照片 + 标签文案 + 时间地点」做成**可自定义比例与背景的艺术卡片**，支持多图轮播、详情留言、多账号、暗黑模式。项目面向微信小程序**测试号**，数据全部落在本地（本地存储 + 用户目录图片），打开即用，无需配置域名/云开发。

> 完整项目分析见同目录《开发报告.md》。

---

## 一、快速开始

1. 微信开发者工具 → 导入项目根目录；
2. AppID 使用 `touristappid`（游客）或你的测试号 AppID，基础库建议 3.x；
3. 编译运行。首次使用点底栏中间「做卡片」体验完整流程。

## 二、四大板块功能速览

| 板块 | 页面 | 能力 |
|---|---|---|
| **制作卡片** | `pages/create` | 相册多图上传、**长按拖动照片调整顺序（第 1 张为封面）**、**照片比例**与**背景风格**分开选择、**10 种自定义底色 + 相册自定义背景图**、标签（**只做挑选**，1~4 个，词条在「我的」管理）、时间/地点、预留长文本、**心情色**、**贴纸（点一下贴上、拖动摆位置、长按撕掉）**、实时预览；支持「编辑」「仿照再作」 |
| **卡片墙（首页）** | `pages/index` | 瀑布流双列按日分组；**标签筛选**与**地点筛选**均为「多选详细浮层」（按使用频率排序 + 已选可删胶囊），**时间自定义起止**，**心情色筛选**；收藏 ♥、按日标题分隔 |
| **卡片详情** | `pages/detail` | 首屏聚焦「大卡 + 标签 + 收藏 / 去评论 / 导出」，下滑才展开创作者故事、评论与留言流；**可翻面看「卡片背面」**（心情色、副标签、收藏与留言数，以及**完整不截断、可滚动的留言墙**、制作者印章）；**「♻ 我也做一张」所有人（含作者）都能用**；多图自动轮播（**触碰图片即暂停**）、自己留言高亮；**留言可被回复**（二级评论，回复会通知被回复者）；**点创作者或留言者头像可进 TA 的主页**；创作者可见「N 人收藏 · M 条留言」；**导出卡片为图片：多张照片合成一张**（含贴纸与心情徽章；自选图片 / 保存相册 / 发送朋友 / 另存原图）并支持微信分享链接 |
| **他人主页** | `pages/user` | 从详情页的创作者、留言者头像进入；展示 TA 的昵称 / 头像 / ID、制作卡片数与收到的收藏数，以及 TA 的全部公开卡片 |
| **我的** | `pages/profile` | 资料（昵称/头像）编辑、**多账号管理**（新建/切换/删除本地账号，卡片·收藏·标签各自独立）、**标签词库管理**（新增 / 改名 / 删除 + 预览）、**🔔 互动反馈**（谁收藏了 / 谁留言了 / 谁回复了，未读角标，可直达卡片或对方主页）、统计、**暗黑模式**开关；「我制作的」为瀑布流并可**长按拖动排序**；「我的收藏」为**拼图墙**——长按自由拖动换位、单卡可放大/缩小自适应、随机倾角 + 🎨 美化 + 🎲 洗牌 |

底部为自定义导航：**首页 | 中央「做卡片」| 我的**。

## 三、视觉与主题

- **夏日水色设计**：浅天青底 + 水蓝主色 + 日光金点缀，界面带体积感（多层投影与内高光）；
- **暗黑模式**基于 CSS 变量（`page` + `.page.dark` token 覆盖），个人页一键切换并全局生效；
- 页面含圆环/圆点/光晕等轻量艺术装饰，深浅色自适应；
- 卡片与面板带**体积感**（多层投影 + 内高光 + 按压下沉），页面/Tab 切换有顺滑淡入过渡，卡片 `popIn`、列表淡入、收藏爱心震动等动效；
- 另有趣味入口：首页「🎲 随机看一张」、收藏拼图墙「🎲 洗牌」与单卡缩放；卡片本身还有**贴纸**、**心情色徽章**与详情页的**翻面**。

## 四、核心设计要点

- **卡片渲染引擎 `card-view`**：同一套 DOM 由 `r-`（比例）与 `s-`（风格）两组 CSS 类驱动 6 种风格 × 6 种比例的自由组合；支持自定义背景 `customBg`（纯色/渐变/图片）并可读性遮罩；多图轮播带自动播放与页码；海报模式主标签大字、其余标签缩小显示并可用 `posterLimit` 限制数量。**要显示的标签行、照片列表、贴纸样式都在 JS 里算好再绑定**（WXML 不允许 `wx:for` 与 `wx:if` 写在同一节点），贴纸拖动通过组件内的 `createSelectorQuery` 把触点换算成百分比坐标回传页面。
- **瀑布流与拼图墙**：首页/「我制作的」按估算高度贪心分入左右两列消除大空档；「我的收藏」用绝对定位拼图墙实现真正的自由拖拽——指针命中即换位、尺寸（半宽/通栏）自适应重排，并按账号持久化。
- **导出与分享**：`utils/cardExporter.js` 用离屏 Canvas 2D 按卡片比例绘制成品图——**多张照片会按 2/3 列网格合成进同一张图**，再叠加主副标签、时间地点与水印；支持保存相册、发送朋友、另存全部原图，以及卡片链接的微信分享。
- **浮层与底部导航**：标签筛选 / 账号抽屉 / 标签词库打开时会临时隐藏自定义底栏，浮层滚动区按屏幕高度动态测量，避免被遮挡或手势穿透底层页面。
- **页面跳转 `utils/nav.js`**：所有 `navigateTo` 都走这里。微信页面栈上限 10 层，**超限后 `navigateTo` 会静默失败**（点了没反应），这里的兜底是在失败时改用 `redirectTo` 把目标页打开。
- **数据层 `utils/store`**：抽象全部本地读写。数据模型自带多用户字段（`ownerId`、按 `uid` 的收藏表与标签词库），后期替换为云开发即插即用。

## 五、数据模型（本地存储）

- 账号：`{uid,nickname,avatar,avatarColor,createdAt}`，多账号并存、任意切换；
- 卡片：`id/ownerId/ownerName/createdAt/ratio/style/customBg/photos[]/phrases[]/timeText/locText/reservedText/mood/stickers[]/messages[]`（贴纸形如 `{ id, emoji, x, y, size, rot }`，`x/y` 是相对照片区的百分比，导出时按同一比例画进图片）；
- 标签（快捷语）：`{id,emoji,text}`，内置 + 自建，自建与“隐藏的内置词”都按账号隔离；
- 留言：`{id,uid,name,avatar,content,at}`；
- 收藏表：`{[uid]:[cardId…]}`。

## 六、目录结构

```
card-studio/
├─ app.js / app.json / app.wxss / sitemap.json / project.config.json
├─ custom-tab-bar/        # 自定义底部导航（可随浮层隐藏/暗色）
├─ data/presets.js        # 内置标签/风格/比例/底色/快捷填入项
├─ utils/util.js          # 时间/ID/工具
├─ utils/store.js         # 本地数据服务层（账号/标签库/图片/卡片/收藏/留言/主题）
├─ components/card-view/  # 模板化卡片渲染引擎
├─ README.md / 开发报告.md
└─ pages/{index,create,detail,user,profile}
```

> 同步说明：卡片可以通过 Canvas 导出成图片保存 / 发送给朋友，也能分享小程序链接；但**跨设备同步**仍然做不到——数据都在本机，所以「换个手机就看不到」是正常的。接入云开发（`getWXContext().OPENID` 获取真实身份 + 云存储）后，替换 `utils/store.js` 即可获得真实的多端多用户能力，前端页面无需改动。
